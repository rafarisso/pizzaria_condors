# Pizzaria Condors

Aplicação web de delivery desenvolvida para uma pizzaria real, com foco em pedidos online, comunicação direta com o cliente e gerenciamento operacional por meio de painel administrativo.

Este projeto representa uma solução prática criada para atender uma necessidade real de negócio: permitir que a pizzaria receba pedidos de forma mais organizada, reduza dependência de plataformas terceiras e tenha mais controle sobre o relacionamento com seus clientes.

## Sobre o projeto

O Pizzaria Condors é um app de delivery funcional, desenvolvido para uso comercial.

A aplicação permite que clientes acessem o cardápio online, escolham produtos, informem seus dados de entrega e finalizem o pedido de forma simples. O fluxo foi pensado para facilitar a experiência do cliente e, ao mesmo tempo, organizar melhor a operação da pizzaria.

Além da interface pública para pedidos, o projeto também conta com um painel administrativo para acompanhamento e gestão de informações importantes do atendimento.

## Objetivo

O principal objetivo deste projeto foi criar uma solução digital simples, direta e funcional para uma pizzaria local.

A proposta foi entregar uma alternativa própria de vendas online, com foco em:

- facilitar pedidos pelo cliente
- organizar informações de entrega
- melhorar o controle operacional
- apoiar o atendimento via WhatsApp
- reduzir atrito no processo de compra
- criar uma presença digital própria para o negócio
- oferecer uma base para futuras automações

## Funcionalidades principais

- Cardápio digital online
- Fluxo de pedido para delivery
- Cadastro de dados do cliente
- Campo obrigatório de CEP
- Busca e organização de informações de entrega
- Integração com WhatsApp para envio de pedidos
- Estrutura de painel administrativo
- Atualização de status de pedidos
- Organização de clientes
- Suporte a imagens dos produtos
- Funções serverless com Netlify Functions
- Deploy web em produção

## Painel administrativo

O projeto conta com um painel voltado para o gerenciamento da operação.

Entre os recursos trabalhados no painel estão:

- visualização de pedidos
- acompanhamento de status
- organização de clientes
- atualização de informações operacionais
- suporte ao fluxo interno de atendimento

O painel foi pensado para tornar a gestão mais simples e acessível, sem exigir ferramentas complexas para a rotina do negócio.
